# Sunset Heat: Solmar Bay

Entry for the make.fun bounty gta6-01 — an original open-world crime game in a
desktop browser. Sunset coastal city, on foot and by car: traffic, pedestrians,
carjacking, a wanted level with police and a helicopter, six story missions,
combat, shops, radio, a HUD with a circular minimap, and a save.

Play it: serve `game/` with any static file server and open `index.html` in
desktop Chrome. No network requests, no build step — three.js is vendored under
`game/vendor/`.

- **Rae Calloway**, getaway driver for fixer Dario Venn and Lena Cross.
- **Solmar Bay**: grid city, beach and ocean, pier and lighthouse, docks, palms.
- **Controls**: WASD move/drive, E enter or steal a car / use a shop / collect,
  F punch, click or G fire the pistol, M radio, P or Esc pause, Enter start.
- **Missions**: six jobs — a first drive, a pickup, a timed delivery, a golden
  crate at the lighthouse, a getaway, and a final run to the harbor.
